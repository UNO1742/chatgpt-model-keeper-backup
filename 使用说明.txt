一、安装（每台电脑首次操作一次）

1. 将 ModelKeeper.exe 复制到目标电脑，双击打开。不需要安装 Python。
2. 点击桌面上的小圆点，在展开的设置卡片里点击“安装 / 更新”。
   程序会复制自身及配套扩展到：
   %LOCALAPPDATA%\ChatGPTModelKeeper
   安装只针对当前 Windows 用户，不需要管理员权限。
3. 点击设置卡片里“浏览器扩展”一行右侧的“安装”。
   程序会把配套扩展交给 Edge 加载，之后在后台保留一个无窗口的 Edge 进程，
   让你每次打开 Edge（任务栏、开始菜单、其它程序里点链接都算）都直接带上扩展。
   安装瞬间如果 Edge 正开着，会被关闭并重新打开一次，已打开的网页会被恢复。
   完成后按钮变为“卸载”。
4. 如果 ChatGPT 网页在扩展加载之前就开着，刷新一次即可。网页上不会出现任何提示或按钮，
   程序只在后台读取模型选择并在需要时纠正。
5. 点击悬浮圆点，用“聊天 / 工作”标签分别修改预设，再点击“保存设置”。
   再次点击圆点或卡片上的 × 收起设置，平时只占约 64×64 像素。
   圆点可以拖动，位置会自动记住；悬浮球不占任务栏位置。
   右键圆点可暂停、恢复、切换开机自启或退出悬浮窗。
   打开卡片时它会从圆点方向展开，收起时缩回圆点（约 0.2 秒）。圆点拖到屏幕顶部、
   左侧或中间时，卡片会自动换到放得下的一侧，不会压住圆点。
   检测到网页模型与预设不一致并改回时，圆点旁会弹出提示气泡，写明改回的值和
   改之前是什么；鼠标移上去暂停消失，5 秒后自动收起。
   退出悬浮窗只退出设置入口，已加载的 Edge 扩展仍按保存的预设工作。

Edge 扩展是程序的组成部分。单独运行 EXE、未启用扩展时，程序无法检测普通
Edge 标签页。此版本未上架扩展商店，无法用商店的静默安装；程序靠“后台锚点”
让扩展每次都可用，悬浮球每 8 秒自检一次：Edge 关闭后会立刻重新准备，Edge 若
被外部拉起却没有扩展，会自动重启一次并恢复标签页。右键圆点选“修复浏览器扩展”
可手动重来，“自动保持扩展启用”可关掉这套自检。
企业管理的 Edge 若禁止开发人员扩展，需要管理员允许或后续正式上架版本。

开机自启：

首次安装 v1.1（含从 v1.0 升级）默认开启当前 Windows 用户的登录自启。
系统登录后只显示小圆点，不弹出设置卡片；不需要管理员权限。
点击圆点，取消“开机自启”并保存，即可关闭；右键菜单也可切换。
关闭后升级会保留关闭状态，不会反复重新开启。
Windows 任务管理器的“启动应用”可以管理本程序；若系统禁用该启动项，
程序尊重系统设置，不会绕过。这里的开机自启指用户登录后的启动。
只运行下载的 EXE 而未安装、未保存时，不会擅自添加启动项。
安装/保存后，自启入口固定指向本机安装目录，不依赖下载文件的位置。

二、预设和中英文

默认聊天：GPT-6 + 极高 / Extra high。
默认工作：GPT-6 Sol + 极高 / Extra high；请根据自己的需要修改。
模型输入框允许自定义，输入网页菜单里的完整名称，例如 GPT-6.1 Sol。
GPT-6 与 GPT-6 Sol 是两个不同的菜单名称；程序严格匹配，不会擅自互换。
思考程度按可见含义匹配，例如：轻度 / Light / Low、中 / Medium、
高 / High、极高 / Extra high、Max、Ultra。
聊天模式里显示“极高”的内部值可能是 max；工作模式里则可能是 xhigh。
程序以网页实际显示和选中状态复核，不把这两个内部值直接混为一谈。
“极高 / Extra high”与单独显示的“Max”分开处理。

三、运行方式

当前可见的 ChatGPT 标签页每约 3 秒读取一次预设；首次连接可能稍慢。
进入新对话、切换聊天 / 工作、修改预设或检测到选择器变化时，会打开
模型菜单核对并纠正，最后再次核对选中状态；稳定状态下每 60 秒复核一次。
因此界面可能短暂显示模型菜单，这是正常的检测操作。
手动修改模型后，通常在下一轮检测纠正；若按钮本身不显示模型变化，
最迟在下次定时复核发现。可点击扩展图标中的“重新检测当前页”立即检查。

程序等待页面空闲约 1.8 秒后操作，检测期间不要连续点击模型菜单。
正在输入、回复生成、打开其他菜单或对话框时会推迟；后台标签页在切回后检查。
程序不会点击发送按钮，不会阻止你在调整完成前发出消息，不能保证抢在
快速按下发送键之前完成调整。以设置卡片底部的“已确认”状态作为完成依据。
程序只改变当前选择器，不能改变已经发出的消息或正在执行的任务使用的模型。

四、暂停和状态

全局暂停：点击圆点，取消“自动检测并调整”并保存。
仅暂停某模式：切换对应标签，取消“应用此模式的预设”并保存。
网页端不显示任何插件界面；状态只在额度助理设置卡片底部的状态行里查看。
“已确认”：当前模型与思考程度已在本轮菜单检查中确认一致。
“未连接”：尚未安装本机程序，或 Edge 未找到本机消息接口。
“等待”：页面未加载完成、无法确认模式、正在生成或用户正在操作（均显示在设置卡片底部）。
“无法调整”：目标模型不在此模式中、不支持该强度、未解锁或网页结构已变化。
失败每 30 秒重试一次，连续三次失败停止；修正原因后点击扩展图标重新检测。
检测节奏：网页内每 3 秒检查一次；标签页切到后台时停止，切回前台立即检查；
你刚刚点过鼠标或敲过键盘的 1.8 秒内不动手；调整被打断后 3 秒重试；
其它失败 30 秒重试、连续三次停止；设置稳定后每 60 秒复核一次。
“等待”只表示下一次检查的时机，不是卡死。
选择器不会自动替换成“最接近”的模型。无法识别当前模式时停止操作。

五、其他电脑、更新、卸载

把同一个 ModelKeeper.exe 发到另一台兼容的 Windows 电脑，重复安装步骤即可。
各台电脑分别保存预设。需要相同预设时，关闭设置窗口后复制安装目录下的
config.json 到另一台电脑的同一安装目录。不要复制账号、Cookie 或浏览器配置。

更新前关闭所有 Edge 窗口及旧设置程序，再运行新 EXE，点击圆点中的“安装 / 更新”。
然后在 Edge 扩展页对本扩展点击重新加载，刷新 ChatGPT；原有预设保留。
保留源码中的 manifest.json 的 key，否则扩展 ID 会改变，需重新安装登记。

卸载：先在 Edge 扩展页移除本扩展，关闭 Edge，然后在 Windows 已安装的应用
中卸载“ChatGPT 模型锁定器”。该操作移除接口、开机自启和开始菜单登记，保留安装文件
和预设。按提示删除 %LOCALAPPDATA%\ChatGPTModelKeeper 即可彻底清理。
若先移除文件而没解除登记，可重新安装后再按上述步骤卸载。

六、数据与兼容范围

扩展权限只有 nativeMessaging 和 chatgpt.com 内容脚本。无网络监听端口，
无需 OpenAI API Key，不读取 Cookie，不上传聊天内容、不收集网页历史。
程序只读取模式按钮、编辑区的属性（不读取输入正文）和模型菜单状态。
config.json 保存在本机，status.json 只含最近的模式、状态和固定说明，
error.log 仅用于程序异常排查；ui.json 记录悬浮球位置，startup.json 记录
是否已完成自启设置；这些文件均在安装目录下。

该工具是独立开发的本机辅助程序，不是 OpenAI 官方产品。
不解锁账号没有权限使用的模型或强度。网页改版后可能需要更新适配器。
中英文识别针对此版模型菜单；其他语言、Firefox、桌面 ChatGPT、手机浏览器
不在当前适配范围。语音界面或某些已有会话如果没有明确的模式标记，程序会
提示无法确认模式；切回标准输入界面或新建明确选择了聊天 / 工作的页面重试。
这是尚未签名的本地构建，未配置商业代码签名证书。
